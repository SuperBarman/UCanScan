# UCanScan

**Escanea, registra y controla.**

## Descripción

UCanScan es una aplicación móvil Android diseñada para gestionar inventarios de múltiples tiendas y bodegas mediante el escaneo de códigos de barras.

Permite consultar existencias, registrar movimientos, realizar conteos físicos y controlar alertas de stock.

## Funcionalidades previstas

- Inicio de sesión con perfiles de usuario.
- Gestión de tiendas y bodegas.
- Consulta de inventario.
- Escaneo de códigos de barras.
- Registro de entradas, salidas y ajustes.
- Conteos físicos y diferencias.
- Historial de movimientos.
- Alertas de reposición.
- Panel gerencial y reportes.

## Tecnologías previstas

- Kotlin
- Jetpack Compose
- Material Design 3
- MVVM
- Room
- Spring Boot
- API REST
